# Medville Diabetes website

Product catalog and lead-qualification website for Medville Diabetes, a
United States supplier of continuous glucose monitors.

Stack: React 18, TypeScript, Vite, Tailwind CSS v4, React Router 7,
React Hook Form + Zod. Hosting: Firebase Hosting. Form intake: Cloud Run
function writing to Cloud Firestore (HIPAA covered products).

## Quick start

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```

## Before doing anything else

Read `CLAUDE.md`. It contains the contractual stack, the HIPAA rules for the
qualification form, the copy rules, and the ordered list of remaining work.
