## CompanyEmail behavior found in source

The sender emails the company inbox a generic submission notification and a
protected-dashboard link. The message body contains no submitted form answers.
It tags the SES message with the lead ID for delivery-event correlation.

The SES configuration requires TLS and publishes delivery, bounce, rejection,
delay and complaint events through EventBridge to a Lambda. That handler updates
the matching lead's notification status and timestamp, ignores deleted leads
and stale message IDs, and does not downgrade delivered messages to delayed.
The recovered caller code includes notification retries and audit entries.
